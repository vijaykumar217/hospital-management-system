# Hospital Management System

A simple **Hospital Management System** developed in **Python using Google Colab** to manage hospital-related records such as patients, doctors, appointments, and hospital operations.

## Project Overview

This project demonstrates the implementation of a hospital management application using Python programming concepts including functions, classes, file handling, and data management.

## Features

* Add and manage patient records
* Add and manage doctor records
* Schedule appointments
* Display hospital records
* Basic hospital administration operations

## Technologies Used

* Python
* Google Colab
* Object-Oriented Programming (OOP)

## Learning Outcomes

* Python programming fundamentals
* OOP concepts
* Data handling and record management
* Modular program design

## How to Run

1. Open the notebook in Google Colab.
2. Run all cells sequentially.
3. Follow the menu options displayed in the notebook.
